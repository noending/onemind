# 2026-07-09 工作日志

## 一念法藏小程序 UI 全站一致性优化

对小程序进行了四个维度的 UI 系统化优化：元素比例/间距、文字排版层级、按钮触摸尺寸、色彩与对比度（WCAG AA）。

### 核心做法：集中式设计令牌体系
- 在 `app.wxss` 的 `page{}` 上定义全局 CSS 自定义属性（令牌），各页面/组件通过 `var()` 继承，替代原先各页硬编码。
- 令牌分类：
  - 间距 `--space-1`~`--space-8`（8rpx 基数，8-48rpx）
  - 字号 `--text-2xs`~`--text-display`（18-56rpx，`--text-md`=28rpx 三级标题）
  - 行高 `--lh-tight/snug/base/loose`
  - 圆角 `--radius-sm/md/lg/xl/pill`（md=24rpx）
  - 按钮高度 `--btn-h-sm/md/lg` = 88/96/104rpx（88rpx = 44px 触摸标准）
  - 颜色：`--color-bg #f6ecd7`、`--color-ink #2d2018`、`--color-ink-2/3/faint`、`--color-primary #7e2a1c`、`--color-primary-strong #a63127`、`--color-accent`、`--color-border` 等
  - `--color-ink-3 = #6b5544`（对比 ≈5.9:1，替代过浅的辅助文字色以达 WCAG AA）
- 全局类：`.screen`、`.page-body`、`.page-title`、`.section-title`、`.card`、`.tag`、`.pill-button`、`.red-button`、`.muted`、`.divider`。

### 已改造文件
- `app.wxss`：令牌 + 全局类（基础）
- `pages/home/index.wxss`、`pages/library/index.wxss`、`pages/recitation/index.wxss`、`pages/profile/index.wxss`：按钮高度统一到 `--btn-h-*`（全部可点元素 ≥88rpx）；弱棕辅助文字色统一到 `--color-ink-3`；强调色到 `--color-accent-ink`/`--color-primary-strong`。profile 因文件大（1300+行）用 Python 脚本批量替换颜色。

- `components/app-header/index.wxss`：背景→`--color-bg`；`.top-title` color→`--color-ink`、font-size→`--text-md`；`.top-more`→`--color-ink-3`。
