# 一念法藏前台产品需求（统一基线）

更新时间：2026-05-27

## 1. 产品定位

一念法藏是一款以“利益众生”为发心、以“科学记忆”为入口、以“数字法藏”为长期能力的多端修学产品。

一句话定位：

`帮助用户更轻松地背会经咒，并通过长期内容与权限体系守护数字法藏。`

当前前台主线采用三模式协同：

- 趣味背诵：成长养成表达，降低开始门槛。
- 科学背诵：严肃训练表达，强化可解释复习节奏。
- 日常读诵：独立习惯表达，强调每日完成与连续性。

## 2. 用户角色

- 普通修学用户：希望轻松开始、持续坚持。
- 深度修学用户：需要晨晚课、长期持诵与更高质量内容。
- 内容付费用户：愿为音乐、唐卡、能量画、专题内容付费。
- 组织相关用户：后续需要组织内内容与权限协同（Phase 4 对接）。

## 3. 前台信息架构（当前唯一口径）

底栏固定为：

- 今日
- 选内容
- 商城
- 我的

说明：

- 原“计划”不在底栏，计划内容整合到“我的”页面。
- 训练页、读诵页、计划明细页属于二级页面。

## 4. 核心用户闭环

### 4.1 背诵闭环

`选内容 -> 选模式（趣味/科学）-> 生成计划 -> 每日训练 -> 结果反馈 -> 下一次复习`

### 4.2 读诵闭环

`选内容或今日读诵入口 -> 进入读诵 -> 完成打卡 -> 连续天数累计 -> 次日提醒`

### 4.3 协同规则

- 读诵记录不直接等同“已背会”。
- 读诵完成可给出“加入明日复习”建议，但不自动改写掌握状态。

## 5. 页面需求

## 5.1 今日页

目标：

- 用户打开即知道今天要做什么。

需求：

- 展示三类任务卡：`科学复习`、`成长背诵`、`今日读诵`。
- 每张任务卡显示标题、当前进度、推荐动作。
- 展示节日专题入口与推荐内容。
- 无任务时展示空状态并引导去“选内容”。

验收：

- 接口返回三类任务时可按组渲染。
- 完成训练或读诵后，返回今日页数据实时更新。

## 5.2 选内容页

目标：

- 用户快速选到合适内容并进入正确模式。

需求：

- 支持类别筛选：全部、短咒、短偈、经文片段。
- 内容卡展示：标题、长度、预计天数、场景、预览。
- 展示模式适配：`defaultMode`、`supportedModes`、是否支持读诵。
- 点击内容后弹出模式选择层：趣味背诵 / 科学背诵 / 日常读诵。

验收：

- 同一用户同一内容同一模式存在未完成计划时，复用计划不重复创建。
- 选择“日常读诵”可直接进入读诵页，不强制创建背诵计划。

## 5.3 训练页（背诵）

目标：

- 通过结构化训练提升真实记忆效果。

需求：

- 顶部展示：模式、当前天数、总天数、进度条。
- 科学背诵阶段：拆段跟读、首字提示、遮挡回忆、填空复现、整段复诵、抽查巩固（首版可逐步开放）。
- 趣味背诵阶段：成长阶段（初见/熟悉/稳定/通顺/已持诵）、点亮反馈、当日任务感。
- 完成后反馈：`needs_work` / `stronger` / `mastered`，可附 `selfRating`、`latencyBand`、`mistakeCount`。

验收：

- 提交反馈后写入任务结果并更新计划。
- 我的页成长数据与掌握数据同步变化。

## 5.4 读诵页（日常读诵）

目标：

- 建立独立读诵习惯，不与背诵完成混淆。

需求：

- 支持三类读诵：自由读诵、晨晚课读诵、主题读诵。
- 支持记录轮次/时长/完成状态/备注。
- 读诵完成后可提示“加入明日复习建议”。

验收：

- 不创建背诵计划也可完成读诵并累计连续天数。
- 读诵记录可在我的页展示。

## 5.5 商城页

目标：

- 在不破坏修学气质前提下验证商业表达。

需求：

- 展示主题活动、音乐专辑、唐卡/能量画。
- 维持简洁、庄重、克制视觉，不做强促销噪音。
- 首版以展示和转化验证为主，不接真实支付闭环。

验收：

- 列表排版在主流机型不溢出、不挤压。
- 商品信息与修学主线共存，不喧宾夺主。

## 5.6 我的页

目标：

- 用户看到长期修持进展和系统状态。

需求：

- 展示记忆连续天数、读诵连续天数、已掌握数量、最近里程碑。
- 展示计划列表（整合原计划页核心信息）。
- 展示平台能力、提醒设置、开发态自检入口。
- 支持微信授权状态展示与切换。

验收：

- 计划、训练、读诵的核心统计均可从后端拉取并回退本地兜底。

## 6. 业务规则（前台）

## 6.1 模式规则

- `scientific` 与 `playful` 各自创建计划，不互相覆盖。
- 同模式重复创建计划时，优先复用未完成计划。

## 6.2 复习规则

- 漏练任务顺延到今天，不因漏一天使计划失效。
- 结果映射：
  - `needs_work`：继续巩固。
  - `stronger`：按计划推进。
  - `mastered`：可进入已掌握状态。

## 6.3 合规规则

- 经文、咒语、仪轨必须保留来源、版本、校对状态。
- 敏感或内部内容默认非公开。
- 对外文案不夸大功效，不使用低俗或神化营销。

## 7. 阶段路线与 DoD

## 7.1 Phase 1（前台 MVP）

范围：

- 今日、选内容、训练、商城、我的五页可演示闭环。

DoD：

- 底栏结构固定为今日/选内容/商城/我的。
- 选内容到训练闭环可跑通。
- 计划信息可在我的页查看。

## 7.2 Phase 2（多端验证）

范围：

- 微信、iOS MiniApp、Android MiniApp、OHOS MiniApp 的安全区/资源/跳转/存储验证。

DoD：

- 四端至少完成一轮基准复测记录。
- 已知差异有清单与降级策略。

## 7.3 Phase 3（内容与提醒增强）

范围：

- 后端驱动内容、计划、提醒、登录、三模式任务聚合。

DoD：

- 今日任务接口返回 `scientificTasks`、`playfulTasks`、`recitationTasks`。
- 前台完成“后端优先、本地兜底”。

## 7.4 Phase 4（组织与数字法藏）

范围：

- 组织、资产、权限、审计与交接能力前后台闭环。

DoD：

- 公开/登录/组织内/指定人员/私密五级可见策略可验证。
- 关键操作有审计日志可追踪。

## 8. 指标体系（MVP + 增强）

- 首次计划创建率
- 三日复习完成率
- 七日留存率
- 背会率（内容维度）
- 日常读诵连续打卡率
- 第二段开启率
- 节日专题转化率
- 商城内容点击率与请购转化率
