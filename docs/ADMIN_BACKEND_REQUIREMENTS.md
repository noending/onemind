# 一念法藏管理后台产品需求（统一基线）

更新时间：2026-05-27

## 1. 后台定位

管理后台用于支撑三类核心能力：

- 修学内容运营：经文/咒语/节日/专题配置。
- 记忆与读诵运营：趣味背诵、科学背诵、日常读诵配置与统计。
- 数字法藏管理：资产沉淀、权限控制、审计追踪与交接防丢失。

## 2. 角色与权限范围

## 2.1 角色

- 超级管理员：全平台配置、管理员管理、全局审计查看。
- 平台运营：公共内容、节日专题、商城运营、看板查看。
- 内容编辑：内容创建编辑、分段维护、素材关联。
- 审核员：内容审核、发布/驳回、敏感内容把关。
- 组织管理员：本组织成员、内容、资产与权限管理。
- 资料维护人：组织资产上传维护，不可管理组织角色。
- 只读成员：仅查看被授权资源。

## 2.2 权限动作

- 查看
- 创建
- 编辑
- 发布
- 下架
- 授权
- 下载
- 审核
- 查看日志

## 2.3 可见级别（统一）

- `public`
- `registered`
- `member`
- `restricted`
- `private`

## 3. 后台模块需求

## 3.1 仪表盘

目标：

- 快速感知内容运营、记忆行为、读诵行为与资产风险。

核心指标：

- 今日新增用户、今日新建计划、今日完成训练任务。
- 今日读诵完成数、读诵连续打卡人数。
- 科学/趣味模式计划占比。
- 节日专题触达与加入计划率。
- 待审核内容数、高风险权限变更数。

验收：

- 支持时间区间筛选。
- 支持按组织、内容类型、模式维度筛选。

## 3.2 内容管理

管理对象：

- 短咒、短偈、经文片段、仪轨片段、开示内容。

关键字段：

- 标题、副标题、正文、分段、预览。
- 类型、长度等级、计划天数、场景。
- 来源说明、版本说明、审核状态、发布状态、访问级别。

功能：

- 创建、编辑、下架、复制、版本追踪。
- 内容分段编辑。
- 关联音频/图片/唐卡/能量画。

验收：

- 发布前必须有审核记录。
- 修改已发布内容时保留版本痕迹。

## 3.3 内容模式配置（新增核心）

目标：

- 让每篇内容可配置“适合哪种训练/读诵方式”。

配置项：

- `defaultMode`：默认模式（scientific/playful）。
- `supportedModes`：支持模式集合。
- `supportsRecitation`：是否支持日常读诵。
- `recommendedRecitationTime`：推荐时段（morning/evening/custom）。
- `recitationTheme`：专题标签。

验收：

- 配置变更后前台“选内容”与“模式弹层”实时生效。
- 不支持读诵的内容在前台不显示读诵入口。

## 3.4 节日专题管理

目标：

- 节日当天给出恰当内容引导，形成长期修学习惯。

功能：

- 节日创建与维护（农历、公历、人物、说明）。
- 关联推荐内容与推荐资产（音频、图片等）。
- 设置发布状态与排序。

验收：

- 节日列表仅展示已发布且有效数据。
- 前台首页节日入口可回溯到后台配置项。

## 3.5 资产管理（音乐/唐卡/能量画/文档）

目标：

- 统一管理数字内容资产，避免散落和丢失。

功能：

- 资产新增、编辑、下架。
- 可见级别设置与组织归属设置。
- 内容关联关系维护。

验收：

- 访问级别变化必须写审计日志。
- 下架资产不可被公共内容接口继续引用。

## 3.6 记忆与读诵运营

目标：

- 后台可观测三模式运行质量与用户习惯形成。

功能：

- 查看计划分布：科学/趣味。
- 查看训练会话记录（practice sessions）聚合统计。
- 查看读诵目标与读诵会话（recitation goals/sessions）统计。
- 查看今日任务分组产出质量（scientific/playful/recitation）。

验收：

- 至少支持按内容与时间维度查看训练/读诵趋势。

## 3.7 组织与成员管理

目标：

- 支持组织级资料沉淀与稳定交接。

功能：

- 组织创建、成员维护、角色赋权。
- 组织资产与组织内容权限可配置。

验收：

- 组织管理员只能管理本组织资源。
- 指定人员权限变更可审计。

## 3.8 审计日志

目标：

- 对关键行为可追踪、可回放、可复盘。

必须记录事件：

- 内容新增/编辑/下架/发布。
- 资产新增/编辑/下架/权限变更。
- 组织成员角色变更。
- 管理员登录与敏感操作。

验收：

- 审计日志不可被普通运营角色删除。

## 4. 后台优先级

## 4.1 P0（当前推进）

- 管理员登录与会话校验。
- 内容管理 + 模式配置。
- 节日专题管理。
- 资产管理基础能力。
- 审计日志基础能力。

## 4.2 P1（Phase 3 增强）

- 训练/读诵运营看板。
- 通知任务后台派发管理。
- 商城内容运营增强。

## 4.3 P2（Phase 4 深化）

- 组织权限精细化（指定人员、有效期、授权理由）。
- 资产版本与交接流程。
- 下载/访问行为细粒度审计。

## 5. 与前后台接口对齐约定

- 前台任务聚合以 `GET /api/today-focus` 为准。
- 内容模式能力以 `content_mode_configs` 为准。
- 训练行为统计以 `practice_sessions` 为准。
- 读诵行为统计以 `recitation_goals` + `recitation_sessions` 为准。
- 详细字段以 `API_CONTRACT.md` 和 `backend/schema.sql` 为最终对齐依据。

## 6. 验收标准（阶段性）

- 管理后台配置的内容模式可直接影响前台模式选择与任务分组。
- 新增内容/资产/权限变更均可追溯审计。
- 组织成员变更不影响历史资产归属与访问策略。
- 三模式与读诵统计数据可在后台正确聚合展示。
