## 对照记录

1. 初版桌面总览纵向密度过高，底部模块未进入首屏；窄屏待办和指标为单列，首屏过长。
2. 将桌面顶栏收至 52px，总览数据行按信息密度压缩；窄屏待办和指标改为双列，主操作保持全宽。
3. 修复 Recharts 固有宽度导致的 80px 窄屏溢出，最终 `scrollWidth` 与 390px 视口一致。
4. 最终桌面总览主体底部位于 1060px，设计稿同高视口内完整可读；差异仅来自真实数据量和未伪造的业务模块。
